# Ultragon — 3D Landing Page

This repository contains a beautiful, responsive, 3D landing page for Ultragon — a versatile Discord bot that "does anything".

Features:
- 3D hero built with Three.js (interactive, mouse-parallax)
- GSAP-powered entrance animations
- Responsive, accessible layout with features and sample commands
- Ready to deploy on GitHub Pages

Live preview
If you enable GitHub Pages for this repository (Settings → Pages → Deploy from `main` branch), the site will be available at:

https://traderamx81-boop.github.io/ultragon-bot-landing/

Local preview
1. Clone the repo:
   ```bash
   git clone https://github.com/traderamx81-boop/ultragon-bot-landing.git
   cd ultragon-bot-landing
   ```
2. Open `index.html` in your browser. No build step required — everything is CDN-hosted.

Customize
- Replace `logo.svg` with your own logo (keep the filename or update the markup).
- Replace the placeholder invite URL in `script.js` with your bot's OAuth2 invite link.
- Edit colors in `styles.css` (primary color is `--primary`).
